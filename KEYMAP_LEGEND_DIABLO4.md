## Layer 0: DIABLO (Base Skills Layer)

**Optimized for Diablo 4 farming with 6 skill slots**

**Left Hand - Skill Access:**
```
Row 1: [ESC]   [1]    [2]    [3]    [4]    [5]   [BSPC]
Row 2: [TAB]   [S1]   [S2]   [S3]   [S4]   [S5]  [toggle SYMBOLS]
Row 3: [CTRL]  [A]    [S]    [POT]  [F]    [S6]
Row 4: [SHFT]  [Z]    [X]    [C]    [V]    [TP]  [toggle NAV]
Row 5: [ALT]   [NO]   [CTRL] [GUI]  [HOTBAR]

S1-S6 = Skill slots 1-6
  - S1-S5: Primary skills (easy reach, use frequently)
  - S6: Mobility, defense, or off-hand utility
POT = Emergency potion (sends Q key - D4 default)
TP = Town Portal (sends T key - D4 default)
HOTBAR = Hold for alternate skill bindings
```

**Right Hand - Utilities:**
```
Row 1: [=]   [I]    [C]    [M]    [S]    [L]   [BSPC]
Row 2: [RBRK] [Y]    [U]    [I]    [O]    [P]   [NO]
Row 3: [H]   [J]    [K]    [L]    [;]    [']
Row 4: [LBRK] [N]    [M]    [,]    [.]    [/]   [SHFT]
Row 5: [LEFT] [UP]   [DOWN] [RIGHT][FN]

I = Inventory (mapped)
C = Character sheet (mapped)
M = Map (mapped)
S = Skills/Status (mapped)
L = Log (mapped)
Arrows for camera control or utilities
```

## Performance Settings

**Diablo 4 Optimizations:**
- TAPPING_TERM 0 = Zero tap-hold latency (instant key detection)
- OLED_UPDATE_INTERVAL 100 = Only update display every 100ms
- WPM_ENABLE disabled = Reduce CPU overhead
- OLED shows "DIABLO 4" + layer name

## Farming Tips

1. **Skill Positioning**: Put your spenders in S1-S3 (most used)
2. **Mobility**: S5 or S6 for teleport/leap
3. **Defense**: Easy-to-reach spot for protection spells
4. **Potions**: D key is pinky-accessible panic button
5. **Town Portal**: V key for fast escape to town
6. **Force Move**: Use scroll wheel for precise kiting
7. **Inventory**: Quick stash management with INVENTORY layer

## Troubleshooting

**Skills not casting?**
- Verify D4 has focus (Alt+Tab to game)
- Check default keys 1-6 work in D4
- Rebuild with `qmk clean && qmk compile -kb ergodox_infinity -km diablo4`

**Latency issues?**
- TAPPING_TERM 0 already handles this
- Try reducing OLED_UPDATE_INTERVAL to 150ms

**Potion not healing?**
- Verify Q key works in game
- Check D key sends Q correctly
